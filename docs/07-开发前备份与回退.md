# 开发前备份与回退

物业费功能开发前，请先建立 **代码 + 数据库 + 业务 JSON** 三层备份，确保可随时回退。

## 一键备份

```bash
cd "/path/to/金蝶招商管理看板（标准版20260402）"

# 推荐：代码打 Git 标签 + 打包本地 pb_data + 迁移快照 + JSON 导出（需 PB 已启动）
bash scripts/create-dev-baseline-backup.sh

# 仅标签 + pb_data（PocketBase 未启动时）
bash scripts/create-dev-baseline-backup.sh --skip-json
```

备份输出目录：`backups/pre-mgmt-fee-<时间戳>/`

| 文件 | 用途 |
|------|------|
| `git-baseline.txt` | 记录 Git SHA、分支、标签名 |
| `pocketbase-pb_data.tar.gz` | **整库回退**（SQLite + 附件） |
| `pocketbase-pb_migrations.tar.gz` | 当时迁移脚本快照 |
| `json/<project_id>.json` | 按园区业务数据（`migrate-json-to-pb.mjs` 可恢复） |
| `MANIFEST.json` | 备份清单 |

环境变量（JSON 导出，可从 `.env.local` 读取）：

```bash
export PB_URL=http://127.0.0.1:1002
export PB_ADMIN_EMAIL=你的管理员邮箱
export PB_ADMIN_PASSWORD=你的管理员密码
```

单独导出 JSON：

```bash
BACKUP_OUT_DIR=backups/manual-json-export \
  node scripts/export-pb-dashboard-backup.mjs
```

## 回退代码

```bash
# 查看基线标签
git tag -l 'baseline/pre-mgmt-fee-*'

# 回退到某次备份对应的代码（只读检查）
git checkout baseline/pre-mgmt-fee-YYYYMMDD-HHMMSS

# 回到开发分支继续工作
git checkout feature/shenzhen-management-fee
```

若已在开发分支提交了想撤销的改动：

```bash
git reset --hard baseline/pre-mgmt-fee-YYYYMMDD-HHMMSS
```

## 回退本地 PocketBase 数据

**先停止 PocketBase 进程**，再执行：

```bash
BACKUP=backups/pre-mgmt-fee-YYYYMMDD-HHMMSS   # 换成实际目录
rm -rf pocketbase/pb_data
tar -xzf "$BACKUP/pocketbase-pb_data.tar.gz" -C pocketbase
# 启动 pocketbase
```

## 回退单个园区业务数据（JSON）

不恢复整库、只恢复某一园区时：

```bash
node scripts/migrate-json-to-pb.mjs \
  "$PB_URL" "$PB_ADMIN_EMAIL" "$PB_ADMIN_PASSWORD" \
  backups/pre-mgmt-fee-.../json/shenzhen_park.json \
  shenzhen_park \
  --replace
```

`--replace` 会 **删除并重建该 project_id 下全部 pb_* 行**，不影响其他园区。操作前请再次确认 `project_id` 与备份文件一致。

## 开发分支约定

- 功能开发分支：`feature/shenzhen-management-fee`
- 基线标签前缀：`baseline/pre-mgmt-fee-*`
- 重大里程碑可再执行一次 `create-dev-baseline-backup.sh`

## 生产环境

生产 PocketBase 若不在本机 `pocketbase/pb_data`：

1. 在服务器上对 `pb_data` 做文件级备份或官方导出；
2. 对本机或能访问生产的实例运行 `export-pb-dashboard-backup.mjs`；
3. 将 `backups/` 目录复制到安全存储（勿提交 Git）。

`backups/` 已加入 `.gitignore`，避免误提交业务数据。
