## 3. 从云端拉取数据到本地

### 方式 A：JSON 备份（推荐，可跨机器）

在**能访问云端 PocketBase** 的机器上：

```bash
export PB_URL=https://你的云端PB地址
export PB_ADMIN_EMAIL=管理员邮箱
export PB_ADMIN_PASSWORD=管理员密码

BACKUP_OUT_DIR=backups/cloud-pull-$(date +%Y%m%d) \
  node scripts/export-pb-dashboard-backup.mjs
```

将生成的 `backups/cloud-pull-*/` 目录拷到本机项目下，按园区导入：

```bash
node scripts/migrate-json-to-pb.mjs \
  http://127.0.0.1:1002 \
  "$PB_ADMIN_EMAIL" \
  "$PB_ADMIN_PASSWORD" \
  backups/cloud-pull-xxx/shenzhen_park.json \
  shenzhen_park \
  --replace
```

`--replace` 仅重建该 `project_id` 数据，不影响其它园区。

### 方式 B：直接连云端 PB 测前端（不改本地库）

`.env.local` 中设置：

```env
VITE_POCKETBASE_URL=https://你的云端地址
```

`npm run dev` 后登录云端账号即可测 UI（**勿在未备份情况下保存**，以免误改生产）。


```bash

```

浏览器打开 Vite 提示的地址（默认 `http://127.0.0.1:1001`）。

## 6. 深圳物业费功能验收清单

1. 切换园区为 **深圳**，打开合同：可见「物业费条款」，可填 **元/月/㎡** 单价、免物业费、起算日（同入驻 / 自定义）。
2. 保存合同后，**财务报表 → 物业费应收** Tab 出现应收行；**工作台 → 账单** 有物业费 Tab。
3. 录入 `ManagementFee` 收款并核销，租金 Tab 与物业费 Tab 互不混核销。
4. **工作台 KPI**：预算执行表头可切换 **租金｜物业费｜合计**；年度完成率随 Tab 变化；物业费完成率 = 实收 ÷ 合同应收。
5. **年度经营指标对比**（深圳）：表格含物业费应收/实收/完成率及综合完成率列。
6. 合同列表「月单价」与 `月租金÷面积` 一致（深圳月单价展示，见 `resolveRentUnitPriceForDisplay`）。
7. 物业测试账号（`hide_rent_pricing=true`）：看不到租金单价/租金流水，可看物业费；默认打开物业费相关 Tab。
8. `npm run test` 通过（含 `managementFeeBillingService`、`billingService` 相关用例）。

口径说明见 [06-深圳物业费收款与权限方案.md](./06-深圳物业费收款与权限方案.md) §3.4、§0。

## 7. 部署云端（你确认后再做）

1. 云端先执行备份：`bash scripts/create-dev-baseline-backup.sh`（在服务器或连云端 PB 的环境）。
2. 部署 `dist/` + 更新 PocketBase 二进制并重启（迁移自动跑）。
3. 跑 `init-multi-park.mjs` 或 Admin 中确认深圳 `metadata.managementFeeBilling=true`。
4. 为合同补录物业费单价并保存，核对应收与核销。

回退见 [07-开发前备份与回退.md](./07-开发前备份与回退.md)。
