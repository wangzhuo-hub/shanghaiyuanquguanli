# 移动端与字段口径上线验收记录模板

> 使用方式：每次上线前可运行 `npm run qa:rollout:record -- --env 阿里云生产` 生成一份归档记录，也可手动复制本模板。填写完成后运行 `npm run qa:mobile-screenshot-report -- 截图报告路径` 校验截图报告，再运行 `npm run qa:rollout:record:check -- docs/rollout-records/记录文件.md` 检查关键占位项和截图报告内容是否清完。不要把生产账号密码、token、客户敏感信息或原始个人联系方式写入记录。

截图 QA 必查：

- 固定底部导航不遮挡关注字段、待办卡、园区切换或核心按钮。
- 月度明细、筛选 sheet、楼宇 action sheet 和预算编辑浮层文字清楚可读。
- iPhone 深色外观下，工作台浅色 readable 玻璃、今日待办、关注字段和底部导航不得出现文字发白。
- 系统减少动态效果下，bottom sheet、月度明细、抽屉和加载状态仍能通过标题、焦点、选中态和静态位置表达层级。
- 登录后页面验收不得只提交登录页截图；如无法加载登录态，需要在问题记录中说明原因。
- 641-1023px 下仍使用移动 / 平板轻管理布局，1024px 边界切换符合预期。
- 横滑 chips、月份轨道和楼宇切换有可见滑动提示。
