Design mockups

楼宇管理 · HTML 样式对比

以下为同一组示例数据、五种不同视觉与布局气质。用浏览器分别打开各页全屏对比；确定方向后再迁回 React / Tailwind。

  • 方案 A · 色条 + Chip + 轻阴影 典型现代 SaaS：左侧状态色条、胶囊状态、弱边框大留白，信息层级清晰。
  • 方案 B · 斑马纹楼层 + 极弱描边 用行间底色区分楼层，卡片几乎无框，偏「空气感」后台。
  • 方案 C · 深色顶栏 + 轨道式楼层 头部品牌区压暗，内容区高亮；楼层像时间轴轨道，适合大屏展示。
  • 方案 D · 表格式 + 面积比例条 偏运营录入：行内表格信息 + 横向比例条表达面积，密度高但可扫读。
  • 方案 E · Tab：平面图 / 列表 同一卡片内切换：条带化平面示意 + 表格列表；纯 CSS radio 切换，无脚本。
示例数据与当前截图一致风格（1号楼、4F/3F 部分房源）；宽度按面积比例 flex 模拟。
